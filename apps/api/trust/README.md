- 新しい証明書が公開されたら、ここに追加し、フィンガープリントを入管庁の公開情報と照合してから表に追記する
- 発行者の判定は、カードの証明書と同じ鍵種別(RSA / ECDSA)の証明書だけで行う
- 環境変数 `ZAIRYU_TRUSTED_ISSUERS`(カンマ区切りのパス)で追加の証明書を足せる
