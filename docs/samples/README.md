# 確認用の CSV(架空のデータ)

CSV 取込の同一人物の確認を試すための見本です。氏名・電話番号などはすべて架空です。拠点は「本社」(`dev:setup` で作られる拠点)を使います。

1. `csv_check_step1.csv` を取り込む(新規 3 件: T1001・T1002・T1003)
2. Web で T1002(SAMPLE HANAKO)を開き、「退職の手続き」で退職にする(理由とメモを入れる)
3. `csv_check_step2.csv` を取り込み、プレビューを確認する

| 行 | 社員番号 | 期待する判定 |
| --- | --- | --- |
| 2 | T2001 | エラー: 二重登録の疑い(T1001 と同じ氏名・生年月日。表記ゆれ・日付の書き方違いでも一致) |
| 3 | T2002 | エラー: 以前在籍していた方(T1002 とフリガナ・生年月日が一致。前回の退職理由を表示) |
| 4 | T2003 | 新規 |
| 5 | T2004 | エラー: 同じ氏名・生年月日の人が 4 行目にもある(ファイル内の重複) |
| 6 | T2005 | 新規(生年月日が空欄なので同一人物の確認はしない) |
| 7 | T1003 | 更新(電話番号) |
| 8 | T2006 | エラー: 拠点「存在しない拠点」がない |

確認が終わったら、追加された T1001〜T2005 は Web の登録者の画面から退職・アーカイブにしてください。

## work_hours_sample.csv(週28時間の確認)

`csv_check_step1.csv` を取り込んだあとに、Web の「週28時間」→「勤怠 CSV の取り込み」で読み込みます。

| 社員番号 | 内容 | 期待する結果 |
|---|---|---|
| T1001 | 11/2(月)〜11/8(日)は 4 時間ずつ(ちょうど 28 時間)、11/9・11/10 は 8 時間(11/9 は 出勤・退勤・休憩 の書き方) | 月〜日の区切りでは 28 時間以内だが、11/4〜11/10 の 7 日で 36 時間 → **28時間超過** |
| T1002 | 11/9〜11/13 に 5 時間ずつ(25 時間) | **注意(24時間以上)** |
| T1003 | 11/12 に 2 回勤務(3 時間 + 3 時間 → 合計 6 時間)、11/13 に「3時間30分」 | 問題なし |
| T1003 | 日付が 2026/13/01 の行 | 行エラー(日付) |
| T9999 | 登録されていない社員番号 | 行エラー(登録者がいません) |

- サンプルの人はカード未登録なので「週28時間の確認の対象でない人の行」として数えられ、一覧(対象者=資格外活動の包括許可がある在籍者)には出ません。登録者の画面に「参考表示」で判定と日ごとの時間が出ます。
- 一覧に出すには、カード記載事項の 在留資格=留学・就労制限=就労不可・資格外活動=許可(原則週28時間以内…)の人が必要です。
- 期間は今日までの 4 週間が初期表示です。11 月以外に確認するときは期間を 11/1〜11/30 に変えてください。
