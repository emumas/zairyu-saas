# 確認用の CSV(架空のデータ)

CSV 取込の同一人物の確認を試すための見本です。氏名・電話番号などはすべて架空です。拠点は「本社」(`dev:setup` で作られる拠点)を使います。

1. `csv_check_step1.csv` を取り込む(新規 3 件: T1001・T1002・T1003)
2. Web で T1002(SAMPLE HANAKO)を開き、「退職の手続き」で退職にする(理由とメモを入れる)
3. `csv_check_step2.csv` を取り込み、プレビューを確認する

| 行 | 社員番号 | 期待する判定 |
| --- | --- | --- |
| 2 | T2001 | エラー: 二重登録の疑い(T1001 と同じ氏名・生年月日。表記ゆれ・日付の書き方違いでも一致) |
| 3 | T2002 | エラー: 以前在籍していた方(T1002 とフリガナ・生年月日が一致。前回の退職理由を表示) |
| 4 | T2003 | 新規 |
| 5 | T2004 | エラー: 同じ氏名・生年月日の人が 4 行目にもある(ファイル内の重複) |
| 6 | T2005 | 新規(生年月日が空欄なので同一人物の確認はしない) |
| 7 | T1003 | 更新(電話番号) |
| 8 | T2006 | エラー: 拠点「存在しない拠点」がない |

確認が終わったら、追加された T1001〜T2005 は Web の登録者の画面から退職・アーカイブにしてください。
